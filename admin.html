📩 조별 점수/값 제보 (타임라인)

* 실시간 점수 현황판에서 각 조가 보낸 점수/값 제보가 받은 순서대로 표시됩니다.

🎮 게임별 점수 입력표

* 칸에 점수를 입력하면 조별 총점이 자동으로 합산·동기화됩니다. (빈 칸 = 미입력)
* Enter: 아래 칸 / Shift+Enter: 위 칸 이동

추가 점수 / 감점 부여

* 게임 외 점수는 입력표 하단의 '추가/감점' 행에 누적되어 총점에 합산됩니다.

조(팀) 관리

* 조마다 비밀번호 2개: 조원 비밀번호(일반 조원 입장) / 🕵️ 스파이 비밀번호(해당 조 스파이 입장). 모든 비밀번호는 서로 겹치지 않아야 합니다.

조 이름 조원 비밀번호 🕵️ 스파이 비밀번호 총점 관리

📈 조별 점수 변동 추이 (꺾은선 그래프)

게임 점수 입력 시 게임별로 1개 지점이 자동 기록되며(같은 게임 연속 수정 시 갱신), 추가/감점·수동 기록 시에도 저장됩니다.
